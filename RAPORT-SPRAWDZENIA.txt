MARKIN V2 — RAPORT SPRAWDZENIA, 5 PAŹDZIERNIKA 2026

WYNIK LOKALNY
- 37/37 testów jednostkowych zaliczonych.
- 10 stron generuje się poprawnie; 452 lokalne odwołania i kotwice poprawne.
- Edge/Chromium: 40 widoków (10 stron × 320/390/768/1440 px).
- Brak poziomego przepełnienia, uszkodzonych zdjęć, błędów JavaScript
  i odpowiedzi HTTP z błędem podczas sprawdzania stron.
- Dokładnie jeden nagłówek H1 na każdej stronie.
- W wyświetlanej treści i linkach stron brak Semmelrock i Gatigo.

INTERAKCJE
- Pierwszy slajd pozostaje przy 3999 ms, następny wchodzi przy 4000 ms.
- Transformacja przesuwa element w lewo; sprawdzono kolejne slajdy
  i pętlę z ostatniego na pierwszy bez przejazdu wstecz.
- Pauza, ręczne strzałki, klawiatura i preferencja ograniczonego ruchu.
- Zapis inspiracji, zachowanie po przeładowaniu, lista w oknie,
  usuwanie i czyszczenie, zapytanie o wycenę z nazwą produktu.
- Przygotowanie wiadomości mailto; nie wysłano wiadomości do firmy.
- Filtrowanie produktów po marce, przełączanie aranżacji, mobilne menu,
  filtrowanie realizacji, powiększenie zdjęcia i zamknięcie klawiszem Escape.

IMPORTER I FUNKCJE
- Prawdziwe odczyty stron producentów: 3/3 poprawne źródła, 4 produkty.
- Zdjęcia pobrano i obejrzano; początkowe zdjęcia zoptymalizowano do WebP.
- Nowy schemat danych i magazyn oddzielają produkty od newsów z wersji 1.
- Testy: selekcja produktów, odrzucenie newsów/promocji/usuniętych marek,
  ograniczenie domen, przekierowania, limit rozmiaru, formaty zdjęć,
  fallback po awarii, wymiana dawnych nowości, status częściowej awarii,
  walidacja danych po stronie przeglądarki, kontekst produkcyjny i ETag.
- Trzy funkcje zbudowano lokalnie esbuild-wasm dla Node 22 / ESM.
- Spakowane funkcje importują się. Odczyt nowości: HTTP 200,
  kind=products, 4 produkty, mode=snapshot. Nieprawidłowy hash zdjęcia:
  HTTP 400. Odświeżanie z kontekstu podglądu kończy się bez zapisu.

ZAKRES
To testy lokalne i rzeczywiste pobrania publicznych źródeł. Nie wdrożono
paczki na Netlify, nie wykonano push do GitHub, nie zmieniono domeny ani DNS.
Po wdrożeniu trzeba sprawdzić wszystkie 3 Functions, Run now, zapis Blobs,
wyświetlanie pobranych zdjęć i następny zaplanowany przebieg.

Testy w paczce: npm ci, npm test, npm run build,
node scripts/verify-local.mjs. Kontrola źródeł: npm run news:verify.
